# 题库 → Anki 导入

把题库 markdown 转成 Anki「NPDP 选择题」笔记类型能导入的 TSV。

支持两种来源格式，按题号行的写法自动识别：

| 格式 | 位置 | 题号行 | 解析 |
|---|---|---|---|
| **章节题库** | `docs/npdp/exercise/chapter-N.md` | `1、 [单选] 题干` | ①②③④ 分节，带逐选项解析 |
| **模拟题** | `docs/npdp/mock/*.md` | `**1.** 题干（多选）` | 一整段散文，没有逐选项解析 |

两种格式的差别落在字段上：章节题库能拆出 ③，所以 `noteA…noteF` 有内容；
模拟题只有一段解析，`noteA…noteF` 全空。认不出的格式直接报错，不会产出空 TSV。

## 用法

```bash
python scripts/npdp_to_anki.py docs/npdp/exercise/chapter-1.md
# → docs/npdp/exercise/chapter-1.tsv：51 题

python scripts/npdp_to_anki.py docs/npdp/mock/mock-exam-1.md
# → docs/npdp/mock/mock-exam-1.tsv：6 题
```

零依赖，Python 标准库。输出文件名固定为同目录下的 `.tsv`。

## Anki 导入

1. 先按 [`templates/mcq/README.md`](../templates/mcq/README.md) 建好「NPDP 选择题」笔记类型
2. Anki → 文件 → 导入 → 选 `.tsv`
3. 笔记类型选「NPDP 选择题」，字段分隔符选 **Tab**
4. **勾上「允许 HTML 字段」** —— 字段里的换行是 `<br>`，不勾会原样显示成一堆 `<br>`
5. 字段按列顺序自动对应：`id, question, optionA…F, answer, note, noteA…F, source`
6. 重复处理选「与首字段相同的笔记」 → 更新

第 6 步是 `id` 放在首字段的原因：题库改过之后重跑脚本再导入，Anki 会按 `id`
更新已有卡片，而不是新建一份重复的。注意**复习进度不会因此丢失**。

参考：[Anki 官方文档 · 导入文本文件](https://docs.ankiweb.net/importing/text-files.html)

## 字段映射

| 字段 | 章节题库 | 模拟题 |
|---|---|---|
| `id` | `npdp-<章节>-<题号>`，如 `npdp-1-003` | `npdp-<文件名>-<题号>`，如 `npdp-mock-exam-1-003` |
| `question` | 题干 | 题干（`（多选）` 标记已剥掉） |
| `optionA`…`optionF` | 选项，本题库只有 A–D | 同左 |
| `answer` | 正确答案字母 | 同左 |
| `note` | ①考点提炼 + ②正确答案解析 + ④考点延展 | 「解析：」之后的那段原文 |
| `noteA`…`noteF` | ③ 里对应选项的解析 | 全空（原文没有逐选项解析） |
| `source` | `第1章` | 文档一级标题，如 `NPDP 模拟题 第一套` |

模拟题的 `（多选）` 是格式标记，不是题干内容，会被剥掉 —— 笔记类型由 `answer`
的长度自己判多选，留着会在卡面上重复显示一遍。剥掉之后原文信息没丢：脚本会
核对标记与 `answer` 长度是否一致，对不上就报错（多半是答案键漏抄了字母）。

模拟题的 `id` 前缀取自**文件名**，所以改文件名会让重导入多出一份卡片。
一份模拟题存成 `chapter-1.md` 会被拦下 —— 否则它会拿到 `npdp-1-*` 的 id，
盖掉真正的第 1 章。

## 去重

两层去重对两种格式都生效，都保留首次出现的题号，所以留下来的题号不连续——
缺口就是被去掉的重复题。模拟题目前没有重复，6 题原样留下。

`chapter-1.md` 原有 65 题，去掉 14 题后剩 51 题：

1. **自动**：题干、选项、答案逐字都相同 → 11 组
2. **手工**：题干只差个别字词、选项与答案逐字相同，自动比对抓不到 → 3 组
   （`31 → 1`、`46 → 2`、`52 → 14`，写在修复文件的「## 手工去重」段）

## 修复文件

`chapter-N.fixes.md` 与题库文件同名同目录，保存人工整理过的解析文本。段落的正文
写到下一个 `##` 为止，**正文留空即表示把这一段置空**：

```markdown
## 10 · others

## 10 · note_extra
其他选项：A、B、D 均是平衡计分卡的四个标准维度之一。
```

| 段落 | 含义 |
|---|---|
| `others` | 覆盖 ③其他答案不正确解析（逐选项解析），仅章节题库 |
| `extension` | 覆盖 ④考点延展，仅章节题库 |
| `note_extra` | 追加到 `note` 末尾，两种格式都可用 |

同一文件还有一个 `## 手工去重` 段，用来处理自动比对抓不到的近似重复题，
格式是 `丢掉的题号 → 保留的题号`，每行一条：

```markdown
## 手工去重

31 → 1
46 → 2
```

任何二级标题或 `---` 都会结束上一条段落，所以段落正文不能以 `##` 或 `---` 开头。

## 为什么不猜

题库原文的解析有几处是坏的（合并成一行、漏字母、表格被拍平）。脚本遇到
「③ 拆出来的选项字母和错误答案对不上」时**直接报错退出**，不会猜一个结果出来。

这是刻意的：解析错位不会让卡片看起来坏掉，只会让你背下一条张冠李戴的解释，
而且永远发现不了。报错至少是响的。

改题库后如果脚本报错，说明出现了新的坏格式——看一眼报错指出的题号，在
`chapter-N.fixes.md` 里加一条对应段落即可。目前 `chapter-1.md` 有 **7 题**需要修复，
分属五类毛病（③ 合并成一行、③ 漏字母、③ 粘了表格、③ 末尾多一段、④ 表格被拍平），
逐题清单见 `chapter-1.fixes.md` 开头。

模拟题那一侧同样不猜：题干换行、粘进表格、选项字母不连续、答案字母不在选项里、
`（多选）` 标记与答案长度对不上、缺 `解析：`，全都直接报错。模拟题的解析是散文，
没有 ③ 那一层可以错位，所以哪天真出错，多半是答案键或选项的毛病——正是最该
停下来看一眼的那类。

另外，**认不出格式现在会报错，而不是产出一个 0 题的空 TSV**。旧版遇到没见过的
题号行会静默返回 0 道题，导进 Anki 是空的却没人知道。

```bash
python -m unittest discover -s scripts/tests -t scripts/tests
```

体检」——题库改了导致格式变样，测试会红。`test_npdp_to_anki.py` 覆盖章节题库，
`test_mock_exam.py` 覆盖模拟题，后者还钉住「章节题库那条路的结果一字不变」。
