**重要**：纯前端项目，不含真实后端。

## 技术栈

React19 + TypeScript + Vite + Tailwind 

## 技术规范
1. 样式处理 (Tailwind CSS):
   - 检索 `src/index.css`。提取 CSS 变量，颜色引用必须通过 Tailwind 类名映射到这些变量，**严禁硬编码 Hex/RGB 颜色值**。
   - 响应式布局：必须适配主流的屏幕尺寸。
   - 视觉风格参考`references`目录下的文件。
   - 样式统一：与项目现有 UI 风格、间距、圆角、阴影对齐。
2. 组件使用策略:
   - 优先使用 `src\components\ui` 目录下已有的组件。禁止引入第三方 UI 库。
   - 如果没有现成的组件，使用原生 div/span/button 等基础标签 + Tailwind 自定义封装，组件样式必须与已有的组件保持一致，风格匹配。
3. 图标规范:
   - 用户要求使用图标时：从 `src\assets\icons` 或`Lucide` 图标库中，选择合适的图标。
   - 从 `src\assets\icons` 目录下引入图标时，使用 Symbol 引用方法。
4. 页面结构：
   - 遵循标准布局，按需包含标准的 Header、Sidebar、Main Content 等区域。
5. 数据处理:
   - 使用 `MSW` 实现接口模拟与数据渲染。
   - 禁止在组件或页面内使用硬编码假数据。
   - 数据为空时，必须展示标准化空状态页面。
6. 代码质量:
   - 代码应符合最佳实践，模块化，高维护性，高可读性。
